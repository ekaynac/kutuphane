1. **High — Merging searches breaks authorization consistency.** [src/kutuphane/retrieval.py:172](/home/mega/kobra/src/kutuphane/retrieval.py:172). If access changes atomically from book A to book B during translation, the first search contributes A and the second contributes B. `_merge` retains both without authorizing the combined pool; search can return passages the caller was never simultaneously authorized to receive. Those passages can also reach subsequent models. **Fix:** authorize the complete merged pool in one statement before model use and delivery; retry retrieval if permissions changed.

2. **Medium — The labelling bearer token leaks to other ports.** [experiments/labeling_v5/server.py:433](/home/mega/kobra/experiments/labeling_v5/server.py:433). The cookie contains the reusable authentication token and has `Path=/`. Visiting an attacker-controlled service on the same hostname/IP at another port sends that token to the service. `HttpOnly` and `SameSite=Lax` do not provide port isolation. The attacker can replay it through `X-Label-Token` to read cases and alter labels. **Fix:** use the existing origin-scoped header authentication without a bearer cookie, or deploy on a dedicated hostname isolated from untrusted services.

3. **Medium — Proposer file paths can escape the case directory.** [experiments/labeling_v5/propose.py:146](/home/mega/kobra/experiments/labeling_v5/propose.py:146). `view()` reads arbitrary `local_path` values without containment checks. A crafted case can reference `../../pool.gold.jsonl`, an absolute path, or a symlink outside its folder. The LLM proposer then includes those bytes in its prompt, leaking reference answers or local files. **Fix:** validate case directories and resolve each file beneath its case directory; reject absolute paths, traversal, escaping symlinks, and files without copy permission.

4. **Medium — `current_only` can admit content before its validity begins.** [src/kutuphane/search.py:130](/home/mega/kobra/src/kutuphane/search.py:130). Manifest validation accepts timestamps, but `kstd.effective()` reduces them to calendar dates. For example, `valid_from: 2026-10-27T23:59:00Z` becomes `2026-10-27`, so the new filter admits it at noon that day. **Fix:** preserve timezone-aware timestamps through validity evaluation, or reject timestamps and enforce date-only input explicitly.

5. **Medium — Migration 014 can assign an incorrect embedding-input hash.** [src/kutuphane/migrations/014_vector_input_hash.sql:7](/home/mega/kobra/src/kutuphane/migrations/014_vector_input_hash.sql:7). Before migration 013, indexing sent whole passages, including passages exceeding 24,000 characters. A capable embedding backend could successfully embed them. Migration 014 nevertheless hashes only their prefixes. A subsequent passage with the same prefix and a different suffix can therefore inherit a vector computed from different input. **Fix:** backfill using `truncated`: hash the prefix for truncated vectors and the whole text otherwise; invalidate ambiguous historical rows.

6. **Medium — Rejected oversized questions remain in the query cache.** [src/kutuphane/retrieval.py:160](/home/mega/kobra/src/kutuphane/retrieval.py:160). Answer requests reach embedding and cache insertion before `search.search()` enforces the 1,000-character limit. If embedding succeeds, the oversized question remains as a cache key even though retrieval rejects it. The 256-entry limit consequently does not establish a byte bound. **Fix:** validate query length before embedding or cache lookup, including the answer path, and enforce a cache byte budget.

7. **Medium — Citation parsing neither consistently rejects malformed groups nor fails closed.** [src/kutuphane/answers.py:53](/home/mega/kobra/src/kutuphane/answers.py:53). `[1-2-3]` matches the regex but raises `ValueError` during parsing. Conversely, `[1] [1-100000]` produces only citation `1`, allowing the answer despite the invalid range. The large range is ignored rather than expanded. **Fix:** parse numeric citation groups with an explicit grammar, reject malformed or out-of-range references, and validate endpoints against the passage count before expansion.

8. **Medium — Arbitrary content dates can manipulate recency ranking.** [src/kutuphane/retrieval.py:109](/home/mega/kobra/src/kutuphane/retrieval.py:109). Without manifest validity or a path date, the first date anywhere in passage text determines recency. A contributor can prepend `2099-12-31` to a matching passage and promote it above more relevant evidence for “latest” queries. **Fix:** derive recency from validated publication/event metadata with known provenance; reject future dates and avoid treating arbitrary body text as an authoritative timestamp.
