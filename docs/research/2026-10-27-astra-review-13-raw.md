1. **[P1] Git grafts bypass published-commit confinement — [coderepo.py:175](/home/mega/kobra/src/kutuphane/coderepo.py:175).** `check_git_dir()` accepts `info/grafts`, which Git uses to rewrite ancestry despite `GIT_NO_REPLACE_OBJECTS=1`. Reproduced: an unrelated orphan commit was rejected as `commit_not_published`; adding `<allowed-tip> <orphan>` to `info/grafts` made the same commit pass. This defeats the protection against citing unreachable, force-pushed secrets. **Fix:** reject graft files at registration and every open, and disable graft processing in the confined Git environment.

2. **[P1] Proposal candidates survive read revocation — [notes.py:642](/home/mega/kobra/src/kutuphane/notes.py:642).** Candidate selection uses a separate read decision inside `work()`, but `guard_many` finally checks only `draft.needs()`. Candidate books—and the destination journal’s optional read permission—need not appear there. Revoking a candidate book after selection still returns its text; revoking journal read can still return existence and counts instead of the minimal receipt. Reproduced the candidate disclosure. **Fix:** include receipt permissions in the final authorization snapshot and rebuild or downgrade the receipt when any are lost.

3. **[P1] Ordinary note queries fail after 200 stored code citations — [notesquery.py:250](/home/mega/kobra/src/kutuphane/notesquery.py:250).** `_citations()` sends citations from every loaded note to `verify_many()` before set filtering or pagination. Eleven notes with twenty citations each therefore make `query_notes()` fail with “at most 200 citations per request,” even without a code target or with a tiny page budget. Reproduced this using retired notes that should not enter the default result. **Fix:** evaluate notes in bounded batches, paginate within the verification budget, and avoid verification work for untargeted citations.

4. **[P2] `open_citation` does not revalidate linked books — [notesquery.py:798](/home/mega/kobra/src/kutuphane/notesquery.py:798).** The graph uses all currently readable books, but the final decision checks only the opened note’s book. If another book loses read permission during construction, its link counts—and a cross-book successor reference on a retired note—remain in the response. Reproduced the stale link count after revocation. **Fix:** use the same complete read-set comparison and rerun behavior as `query_notes`, including graph-derived metadata.

5. **[P2] Cancellation can be accepted before insertion yet finish successfully — [answers.py:153](/home/mega/kobra/src/kutuphane/answers.py:153), [jobs.py:178](/home/mega/kobra/src/kutuphane/jobs.py:178).** The cancellation check, answer insertion, and success update are separate operations. A cancellation committed between `check()` and `_store()` is ignored by the final update, which tests only `status = 'running'`. Reproduced a cancellation before insertion followed by a stored answer and `succeeded`. **Fix:** serialize cancellation against answer insertion and job completion in one transaction, checking the cancellation flag while holding the job-row lock.

6. **[P2] Expired workers continue running and storing answers — [jobs.py:160](/home/mega/kobra/src/kutuphane/jobs.py:160).** Renewal can revive an expired lease while its status remains `running`; `check()` ignores both status and lease expiry. Even after another process marks the job `failed: interrupted`, the worker passes its checks and can call the model and insert an answer. Reproduced an answer insertion for an already expired, failed job. **Fix:** require an unexpired running lease for renewal and execution, and atomically fence answer insertion against expiry.

7. **[P2] Hidden-book links leak activity through `since` — [notesquery.py:622](/home/mega/kobra/src/kutuphane/notesquery.py:622).** `_changed()` considers every incident link without checking whether its other endpoint is readable. A new link from an unreadable book makes an otherwise unchanged readable note reappear in polling results, although its visible link count remains zero. Reproduced this with an unreadable source book. **Fix:** derive link-related changes from the authorized graph, requiring read permission on both endpoints.

8. **[P2] Collapse silently removes contradictory members — [notesquery.py:639](/home/mega/kobra/src/kutuphane/notesquery.py:639).** Contradictions are checked only against representatives already retained. With one `same_as` cluster containing older A and B plus newest C, and a `contradicts` edge between A and B, both older notes disappear because neither contradicts C. Reproduced a result containing only C. This violates the contract that contradictory members are never collapsed together. **Fix:** consider all contradiction edges within each cluster when choosing representatives, preserving conflicting alternatives.

9. **[P2] Tombstones bypass the hard response-size limit — [notesquery.py:601](/home/mega/kobra/src/kutuphane/notesquery.py:601).** All `left` entries are placed in the envelope before `_page()` budgets only `items`. A retirement batch can therefore produce an oversized response with no continuation cursor. Reproduced 80 tombstones yielding 10,525 bytes with `max_bytes=8192` and `next_cursor=null`. **Fix:** paginate tombstones alongside items, account for the complete serialized envelope, and preserve continuation state so advancing the watermark cannot skip removals.
