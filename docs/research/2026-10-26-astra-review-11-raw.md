1. **Medium — Same-site CSRF remains possible.** [experiments/labeling_v4/server.py:259](/home/mega/kobra/experiments/labeling_v4/server.py:259) accepts cookie-authenticated POSTs without checking `Origin`, content type, or a CSRF token. A malicious page served from another port on the same host can submit JSON using a `text/plain` fetch; SameSite cookies ignore ports, and CORS does not prevent this write. **Fix:** require the custom authentication header for mutations, or validate an exact allowed origin plus a CSRF token; reject non-JSON content types.

2. **Medium — The server stores fields that were never shown.** [experiments/labeling_v4/server.py:135](/home/mega/kobra/experiments/labeling_v4/server.py:135) validates values independently of visibility. An authenticated request with `shown: []`, `origin: "human"`, and `instruction: "no"` can still store `reviewed_by`, `activate: "allow"`, and `mandate: "yes"`. This contradicts the new record contract. **Fix:** validate the form mode and conditional field set server-side, require mandatory fields in the exposure record, and reject labels outside the permitted shown set.

3. **Medium — Accepted-proposal measurements are forgeable.** [experiments/labeling_v4/server.py:164](/home/mega/kobra/experiments/labeling_v4/server.py:164) accepts arbitrary short strings in `accepted_proposals` for nonblind items. A client can claim acceptance of nonexistent proposals, hidden fields, or values it changed. **Fix:** derive acceptance from the submitted labels and the actual proposals exposed for that item, with a proposal-version identifier. The server-controlled `blind` flag does not protect these nonblind measurements.

4. **Medium — Changing the preset silently discards entered restrictions.** [experiments/labeling_v4/page.html:195](/home/mega/kobra/experiments/labeling_v4/page.html:195) hides rows solely by their current conditions, and `collect()` skips hidden rows. Entering `acceptance: withdrawn` or a validity limit under `decision`, then changing the kind to `note`, silently drops those annotations on save. Closing “All fields” similarly drops entered handling values. **Fix:** keep populated fields visible, or require an explicit clear action before excluding them.

5. **Medium — The blind sample leaks exposure across related items.** [experiments/labeling_v4/server.py:53](/home/mega/kobra/experiments/labeling_v4/server.py:53) assigns blindness independently by item ID, while `batch()` deliberately places group members together. An annotator can see suggestions for one file immediately before labelling a related blind file with the same provenance. The resulting labels are not reliably unanchored. **Fix:** assign blindness by source family/group, isolate duplicate variants, and record prior exposure before treating labels as blind evaluation data.

6. **Low — Blind labels still contain an unanswered default.** [experiments/labeling_v4/page.html:171](/home/mega/kobra/experiments/labeling_v4/page.html:171) initializes `needs_split` to `"no"` even for blind items. Completing only the four required choices records a negative split judgement that the annotator never made, biasing the split-rate measurement. **Fix:** initialize it blank for blind evaluation and either require an explicit answer or retain missingness.

7. **Medium — The cookie fallback fails on reload.** [experiments/labeling_v4/server.py:243](/home/mega/kobra/experiments/labeling_v4/server.py:243) requires authentication before serving `/`, but the page removes `?t=` after storing the token in `sessionStorage`. In the cookie-rejecting browser this change targets, reloading sends neither the query token nor the custom header, so the server returns 401 before JavaScript can recover the session. **Fix:** serve an unauthenticated page shell whose API requests perform authentication, or provide a bootstrap flow that can recover the tab token.

8. **Medium — Oversized single passages bypass the embedding budget.** [src/kutuphane/vectors.py:61](/home/mega/kobra/src/kutuphane/vectors.py:61) sends a passage exceeding 24,000 characters unchanged as a singleton. The supported `whole` profile permits up to 500,000 characters, so such input can still exceed model limits or gateway timeouts and stop indexing. **Fix:** enforce a per-passage embedding limit through a versioned splitting strategy, or explicitly reject oversized passages before dispatch. Reducing batch cardinality does not bound this case.
