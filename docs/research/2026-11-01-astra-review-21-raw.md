1. **Medium — [047_note_applies_to.sql:10](/home/mega/kobra/src/kutuphane/migrations/047_note_applies_to.sql:10): the empty-table check can lose committed feedback.**  
   During an upgrade, an old server can insert feedback in an uncommitted transaction. The migration sees the table as empty, then waits for that transaction when acquiring the DROP lock. Once the writer commits, DROP proceeds and deletes the acknowledged feedback. **Fix:** acquire `ACCESS EXCLUSIVE` on `runbook_feedback` before checking emptiness, within the migration transaction.

2. **Medium — [passagemap.py:75](/home/mega/kobra/src/kutuphane/passagemap.py:75): changed instructions can incorrectly retain a citation successor.**  
   Reproduced: `choose("Allow requests when retries >= 3.", 0, [(0, "Allow requests when retries <= 3.")], same_content=False)` returns `(0, "overlap")`. `_flat()` discards operators and case, so opposite instructions become identical. Readers see `moved` instead of `stale`, defeating #149’s protection against meaning changes. **Fix:** preserve punctuation, operators and case when checking whether the new passage contains the old text; invalidate and recompute affected stored mappings.
