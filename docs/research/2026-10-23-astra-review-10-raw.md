1. **High — [`server.py:170`](/home/mega/kobra/experiments/labeling_v4/server.py:170): An empty token disables authentication.** `load_token()` accepts an existing empty or whitespace-only private file. `authed()` then compares the missing cookie’s empty value against the empty token and authenticates anonymous requests. An interruption between token-file creation and writing can cause this. **Fix:** reject empty/malformed tokens at startup and explicitly reject missing or empty cookies.

2. **Medium — [`propose.py:105`](/home/mega/kobra/experiments/labeling_v4/propose.py:105): Tool signals override explicit model involvement.** `Generated by typedoc\nWritten by ChatGPT` produces `origin: tool`, despite detecting both markers. Setting `needs_split: yes` does not correct the origin. This contradicts docs/11’s rule that any model-produced content makes the item model-origin. Generic phrases such as “this file was generated” also establish no evidence of exclusively written rules. **Fix:** evaluate model involvement first; reserve `tool` for sufficiently specific evidence without conflicting model signals.

3. **Medium — [`propose.py:57`](/home/mega/kobra/experiments/labeling_v4/propose.py:57): Status substring matching turns negative states into acceptance.** Reproduced: both `Status: unstable` and `Status: not approved` propose `accepted`, because `stable` and `approved` match without boundaries or negation handling. **Fix:** parse explicit status values, handle negation, and leave ambiguous prose unclassified instead of prefilling acceptance.

4. **Medium — [`propose.py:167`](/home/mega/kobra/experiments/labeling_v4/propose.py:167): A third-party retraction promotes pending items to accepted.** An item with `known.acceptance: pending` and only `same_key: false` retractions gets an `accepted` proposal. A contest should preserve the source’s state; it cannot establish acceptance. **Fix:** record the contest separately and continue evaluating the existing acceptance/status evidence.

5. **Medium — [`llm_propose.py:124`](/home/mega/kobra/experiments/labeling_v4/llm_propose.py:124): Resuming permanently skips failed requests.** Every recorded ID enters `done`, including timeout, HTTP-error, and parsing-error records. A temporary LLMDAP outage therefore leaves items without proposals even after rerunning successfully. **Fix:** skip only successfully validated proposals; retry error records, with bounded retries/backoff and a clear latest-result policy.

6. **Medium — [`llm_propose.py:71`](/home/mega/kobra/experiments/labeling_v4/llm_propose.py:71): Malformed model output can terminate the entire batch.** A response containing `{"origin":[]}` raises an uncaught `TypeError` during set membership; non-object JSON or an empty `choices` array also escapes the current exception handling. Hostile file content can attempt to induce these response shapes. Conversely, responses without a JSON object become evidence-only “successful” proposals and are permanently skipped. **Fix:** validate the response envelope and require a complete, correctly typed proposal object before storing success; record schema failures per item and continue.

7. **Medium — [`page.html:151`](/home/mega/kobra/experiments/labeling_v4/page.html:151): Concurrent navigation and saving can silently skip unlabeled items.** Double-clicking Save sends two requests for the same `current.item.id`; both successful callbacks increment `pos`, advancing past another item. Switching strata while a save is pending also lets its callback advance the new stratum. **Fix:** disable conflicting controls while saving/loading, bind each operation to its item and navigation generation, and discard stale completions.

8. **Medium — [`kstd.py:149`](/home/mega/kobra/src/kutuphane/kstd.py:149): Software-agent versions are neither preserved exactly nor restricted to meaningful values.** YAML `version: 1.10` becomes numeric `1.1`, conflating distinct generator versions. Booleans and non-finite floats also pass validation; `version: false` is accepted because `bool` subclasses `int`. This undermines the exact generator-version identity promised by docs/11 and permits malformed tool metadata to suppress AI marking. **Fix:** require nonblank string versions and document quoting numeric-looking versions, or preserve their original scalar spelling with a dedicated loader.

9. **Medium — [`packages.py:244`](/home/mega/kobra/src/kutuphane/packages.py:244): Received `tool_made` claims are returned as verified without validation or reconciliation.** A trusted signer can supply arbitrary `tool_made` values, nonexistent paths, or classify a file as tool-made while its enclosed `kstd.yaml` declares `model`. Signature and digest verification still succeed, and the contradictory field reaches the receive response. Publication-time kstd validation does not reconcile this package metadata. **Fix:** validate the field’s schema and paths, derive expected origin metadata from the enclosed validated manifest, and reject contradictions before returning a verified result.
